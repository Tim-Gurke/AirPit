# AirPit 0.0.6 validation

- Touchpad speed is a separate persisted percentage, clamped to 25–300 with a 100 default.
- At 100 the existing one-finger movement calculation is unchanged. The factor is applied only to pointer X/Y, with the existing subpixel carry and HID bounds retained.
- The settings callback applies the stored value to the current touchpad; all newly constructed touchpads load the same value, including fullscreen and orientation rebuilds.
- Reset explicitly stores 100, updates the seek bar and applies the value. Gyro settings retain their separate existing key and callback.
- Existing core regression checks, Android compilation, signature and fresh-source payload comparison run before publication.
- Physical S10/Windows pointer speed, slider/reset interaction and persistence should be checked using the release notes; no physical-device pass is claimed.
