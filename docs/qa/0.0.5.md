# AirPit 0.0.5 validation

- Passed the existing 146 HID/keyboard/motion checks, 426 transmission checks and 2,938 layout/editing transaction checks.
- Passed 23,909 grid/insertion checks covering nearest-grid positioning, constrained edges, old unaligned gaps, vertical cascades, unaffected columns, wide bridging controls, immutable drag baselines, repeated previews, cancellation, saved-state recovery and failed-insertion rollback.
- Randomized insertion tests independently check visible rectangle intersections and verify that neighboring controls keep their horizontal position, size and visibility.
- The visible grid is restricted to the editor viewport and is invalidated when scrolling. Existing stored layouts are not automatically snapped on opening.
- Android compilation, APK signature, source checksum and comparison against a fresh unsigned build are checked before publication; CI verifies the current source and Windows helper.
- No physical S10 or Bluetooth test is claimed. Grid visibility, touch positioning, scrolling, live neighbor movement and save/discard should be checked using the release notes.
