# AirPit 0.0.4 validation

- Passed 146 HID/keyboard/motion checks, 426 transport/cancellation/draft checks and 2,938 individual-control geometry/editing-transaction checks.
- Passed SDK 35 compilation, release checksum, source fingerprint, APK signature and comparison of the signed APK payload with a fresh unsigned build.
- Confirmed that the signing certificate matches 0.0.3.
- Android 9 software emulator, 720 × 1520 pixels at 320 dpi: installed and launched the APK, inspected the normal surface and rounded buttons, entered the editor, and opened individual-element position/size controls. The visible button hit areas were checked for overlap and were disjoint.
- Full interaction testing was interrupted by failure of emulator Android system services during keyboard input. Subsequent shell input and accessibility commands failed because input/settings services were unavailable. No complete on-device save/discard/rotation pass is claimed. Those behaviors are covered by the independent layout and transaction checks.
- S10 physical interaction, Bluetooth delivery, saved arrangement reload and rotation remain manual test cases listed in the release notes.
